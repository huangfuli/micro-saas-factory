# MicroSaaS Agent Factory

AI-native product factory: discover real problems, score opportunities, validate ideas, build MVPs, test, launch, and iterate.

## v0.1 goal

Turn raw demand signals into ranked, structured MicroSaaS opportunities with an auditable scoring model.

Pipeline: `Scout -> Score -> Gate -> Rank -> Analyst -> PM -> Builder -> QA -> Launch`

The first milestone implements Scout + scoring + orchestration. Human approval remains the gate before product generation.
